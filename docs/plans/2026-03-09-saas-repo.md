# OpenFlow SaaS Repo Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Create `/Users/carlo/my_work/openflow-saas/` — a standalone SaaS wrapper that depends on the OSS `openflow` package (local editable install + npm link) and adds full auth (JWT, email, Google OAuth), a landing page, and protected analytics dashboard.

**Architecture:** SaaS repo is a thin wrapper: Python backend imports `openflow` as a local package and mounts its FastAPI router under a larger app that adds auth routes. Frontend imports `@openflow/core` (npm link) and wraps the dashboard in a ProtectedRoute with auth pages. Both repos stay independently deployable.

**Tech Stack:** FastAPI, DuckDB, SQLite (product DB), Fernet encryption, JWT cookies, bcrypt, slowapi, python-jose, Vite 6, React 18, TanStack Query v5, Zustand, Tailwind v4, shadcn/ui, React Router v6

## Task 7: Backend — Main App

**Files:**
- Create: `backend/main.py`

**Step 1: Write `backend/main.py`**

```python
"""OpenFlow SaaS — FastAPI app combining OSS analytics with auth."""
from contextlib import asynccontextmanager
from pathlib import Path

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import FileResponse, RedirectResponse
from fastapi.staticfiles import StaticFiles

from backend.config import get_settings
from backend.api import auth_router
from backend.product_db.migrations import init_product_db, run_migrations
from openflow.core.logging import setup_logging
from openflow import create_router as create_analytics_router

settings = get_settings()


@asynccontextmanager
async def lifespan(app: FastAPI):
    setup_logging(settings.log_level, settings.log_format)
    init_product_db()
    run_migrations()
    yield


app = FastAPI(
    title="OpenFlow SaaS",
    docs_url="/docs" if settings.debug else None,
    redoc_url="/redoc" if settings.debug else None,
    openapi_url="/openapi.json" if settings.debug else None,
    lifespan=lifespan,
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_list,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Auth routes
app.include_router(auth_router)

# Mount OSS analytics under /api (requires JWT auth via get_current_auth_user)
analytics_app = create_analytics_router()
app.mount("/analytics", analytics_app)


@app.get("/api/health")
async def health():
    return {"status": "ok"}


# SPA fallback (production)
dist_path = Path(__file__).parent.parent / "dist"
if dist_path.exists():
    app.mount("/assets", StaticFiles(directory=dist_path / "assets"), name="assets")

    @app.get("/")
    async def root():
        return RedirectResponse(url="/dashboard", status_code=302)

    @app.get("/{full_path:path}")
    async def spa_fallback(full_path: str):
        return FileResponse(dist_path / "index.html")


def main():
    import uvicorn
    uvicorn.run("backend.main:app", host="0.0.0.0", port=8000, reload=settings.debug)
```

## Appendix: Import Reference

| Module needed | Import in SaaS `backend/` |
|---|---|
| Settings | `from backend.config import get_settings` |
| JWT utils | `from backend.core.jwt_utils import ...` |
| JWT auth dep | `from backend.core.jwt_auth import get_current_auth_user` |
| Password | `from backend.core.password import hash_password, verify_password` |
| Rate limit | `from backend.core.rate_limit import limiter` |
| Auth service | `from backend.services.auth_service import ...` |
| Email service | `from backend.services.email_service import ...` |
| Product DB | `from openflow.product_db import get_product_db` |
| Analytics router | `from openflow.main import create_router` |
| Logging setup | `from openflow.core.logging import setup_logging` |

| Component needed | Import in SaaS `frontend/` |
|---|---|
| UI components | `@openflow/core/components/ui/...` (or via stubs at `@/components/ui/...`) |
| Layout | `@openflow/core/components/layout` |
| Analytics pages | `@openflow/core/features/...` |
| cn utility | `@openflow/core/lib/utils` |
| Stores | `@openflow/core/stores` |
| CSS | `@openflow/core/frontend/index.css` (check actual path) |
