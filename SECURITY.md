# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ❌        |

We recommend always running the latest release.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately by emailing **security@stratif.io**. Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

We will acknowledge your report within 48 hours and aim to release a fix within 14 days for critical issues.

## Scope

In scope:

- The stratif.io application (frontend and backend)
- Authentication and credential handling
- Data access and query execution
- Self-hosted deployment configuration

Out of scope:

- Third-party dependencies (report these upstream)
- Issues in your own infrastructure or data warehouse

## Disclosure Policy

We follow responsible disclosure. Once a fix is released, we will credit the reporter (unless they prefer anonymity) in the release notes.
